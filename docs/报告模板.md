## 一、模板定位

本模板是「一镜一梳」曼陀罗解读报告的标准输出格式，同时满足三个场景：

- **来访者阅读**：结构清晰、语言温暖、有具体可操作的建议
- **系统自动生成**：每段内容有明确的数据来源和填充规则，Agent工作流可按章生成
- **疗愈师参考**：专业信息完整，可作为人工解读的辅助底稿

## 三、报告正文结构（共8章）

### 第1章 整体画面直觉

**定位**：给来访者的第一印象，建立情感连接，不做专业判断

**填充规则**：
- 基于画面整体色调、构图、能量感生成3-5句直觉描述
- 本章语言偏向感受性、画面感，不用专业术语（专业术语在后续章节首次出现时给出文内解释， 单版本措辞友好：报告同时面向疗愈师与来访者）
- 结尾用开放式提问引导来访者连接自身感受

**信号层输入**：
- 主导色调（视觉信号映射 第2层 颜色信号）
- 整体构图特征（圆形/花瓣形/几何形等，第2层 形状信号）
- 整体动势（向外舒展/向内收/稳定/破碎，第4层 三圈流动信号）

**示例模板**：

> 这幅曼陀罗整体给人的感觉是 [整体感受词，如"沉静而有力量""灵动却略带紧张"]。
>
> [颜色主导描述，如"大面积的蓝色铺底，像一片深邃的湖水，中央点缀着温暖的黄色光点"]。
>
> [构图感受描述，如"线条从中心向外舒展，又在边缘处收束，仿佛有一股向外探索的冲动，同时又被什么拉住了"]。
>
> 看着这幅画，你心里最先冒出来的感受是什么？

---

### 第2章 主题确认与解读重点

**定位**：锚定用户议题，明确本次解读的聚焦方向

**填充规则**：
- 回应用户提交的主题
- 说明画面信号与主题的关联程度
- 明确本次报告将重点展开的1-2个议题

**信号层输入**：
- 九宫议题分布（视觉信号映射 第1层 九宫位置映射 + 第2层 颜色信号）
- 主题相关宫位的能量强弱判断
- 主题匹配度计算（用户主题 vs 画面能量最集中的议题）

**数据来源**：
- 用户输入的 theme 字段
- 九宫议题分布计算结果
- 主题与画面信号匹配度

**示例模板**：

> **你提出的主题**：{用户主题}
>
> **画面回应**：从画面的[某特征，如"离宫位置的红色偏弱、坎宫蓝色偏深"]来看，这个主题确实是你当下能量状态中比较突出的一条线。
>
> **本次解读重点**：
> 1. **{主议题1}**——对应画面中{宫位位置+颜色特征}
> 2. **{次议题2}**——对应画面中{宫位位置+颜色特征}
>
> 我们先从能量最集中的地方说起。

---

### 第3章 三圈结构解读

**定位**：从内中外三圈结构看"内在—外在—行动"三层关系

**专业背景**：
- 内圈 = 内在核心 / 潜意识 / 自我关系
- 中圈 = 关系层面 / 情绪互动 / 他人关系
- 外圈 = 外在行为 / 行动表达 / 世界关系

**填充规则**：
- 分别描述内、中、外三圈的主导颜色、元素特征
- 每圈给出1-2句解读，结合该圈对应的心理层面
- 最后总结三圈的一致性或冲突点

**信号层输入**：
- 三圈边界判定（视觉信号映射 第1层 三圈边界判定）
- 每圈主导颜色和元素（第2层 颜色/形状信号）
- 三圈能量流动模式（第4层 承接/断裂/贯通/外散/收缩，视觉信号映射 第4层）

**示例模板**：

> **内圈（内在核心）**：{内圈主导颜色和元素}
>
> 内在状态偏向{解读，如"稳定、有中心感，但略显封闭"}。你内心深处其实{深层特质描述}。
>
> **中圈（关系层面）**：{中圈主导颜色和元素}
>
> 在关系中，你通常表现为{关系模式描述，如"主动付出、照顾他人，但容易把自己的需求放在后面"}。
>
> **外圈（外在行动）**：{外圈主导颜色和元素}
>
> 外在行动上，你{行为模式描述，如"看起来很有条理、按部就班，但内在的热情没有完全释放出来"}。
>
> **三圈关系总览**：
> {一致性/冲突点总结，如"内圈的火（热情）在外圈没有充分表达出来，中间被中圈的土（责任、承载）压住了，形成了'心里有火、行动上却迈不开'的模式"}。

### 第4章 五行能量总览

**定位**：专业解读的核心章节，给出五行能量的整体判断

**填充规则**：
- 用表格形式展示五行能量的相对强弱
- 每行给出一行定性判断（偏旺/适中/偏弱）+ 一句话解读
- 最后总结整体能量格局（如"水木两旺、火偏弱"）

**信号层输入**：
- 五行元素识别结果（视觉信号映射 第2层 颜色/形状/结构信号）
- 各元素面积、深浅、位置加权（五行解读.md 第2.3、2.4节）
- 过渡色/暧昧色的五行归属判定（五行解读.md 第2.1.2节）

**数据来源**：
- 画面元素识别结果（颜色、面积、深浅、位置）
- 五行解读.md v0.3.0 五行能量判定规则
- 视觉信号映射.md v0.1.1 信号识别规则

**示例模板**：

| 五行 | 能量状态 | 画面依据 | 一句话解读 |
|------|----------|----------|------------|
| 木 | 偏旺 | 绿色面积大，主要分布在震宫、巽宫 | 行动力和成长欲强，但容易急躁、想同时做很多事 |
| 火 | 偏弱 | 红色/橙色少，离宫位置颜色浅，以粉色为主（弱火） | 热情和方向感不足，容易感到迷茫、缺乏动力 |
| 土 | 适中 | 黄色分布均匀，中宫稳定 | 承载能力和安全感基本在线，是你的"底盘" |
| 金 | 适中 | 白色分布在兑宫、乾宫，量适中 | 价值感和边界感尚可，但在关系中仍有提升空间 |
| 水 | 偏旺 | 蓝色/黑色面积大，坎宫位置深 | 情绪丰富、感受力强，但容易思虑过多、内耗 |

> **整体能量格局**：水木两旺、火偏弱——典型的"想得多、做得少、热情没点燃"的模式。你的能量更多在"思考和感受"层面流动，在"行动和创造"层面没有完全释放出来。

### 第5章 九宫议题分布

> **MVP 使用声明**：MVP 解读对象为标准中心对称曼陀罗，九宫信息折叠、宫位读数无合法画面来源，本章在 MVP 报告中**降级为"议题清单"形式**——列出来访者主动提出的议题及关联状态，不使用九宫格方位图与宫位能量读数。非中心对称图案的九宫解读为架构预留能力，届时本章需整体重构。

**定位**：将五行能量映射到具体生活领域，让来访者看到能量在不同议题上的分布

**填充规则**：
- 按九宫格排列，每宫标注议题名称 + 能量状态
- 重点标注能量异常（过旺/过弱）的宫位
- 给出2-3个最突出的议题方向

**信号层输入**：
- 九宫位置映射（视觉信号映射 第1层 九宫位置映射）
- 各宫位的颜色/元素识别结果（第2层 元素识别信号）
- 能量强弱判定（偏旺/适中/偏弱）

**数据来源**：
- 九宫位置与颜色对应关系
- 议题.md 八大议题定义

**示例模板**：

```
┌─────────┬─────────┬─────────┐
│ 巽宫     │ 离宫     │ 坤宫     │
│ 天赋成长  │ 事业发展  │ 人生卡点  │
│ 偏旺    │ 偏弱    │ 适中     │
├─────────┼─────────┼─────────┤
│ 震宫     │ 中宫     │ 兑宫     │
│ 情绪模式  │ 自我核心  │ 亲密关系  │
│ 偏旺    │ 稳定     │ 适中     │
├─────────┼─────────┼─────────┤
│ 艮宫     │ 坎宫     │ 乾宫     │
│ 身体健康  │ 原生家庭  │ 财富关系  │
│ 适中     │ 偏旺    │ 适中     │
└─────────┴─────────┴─────────┘
```

> **能量最集中的议题**：
> 1. **情绪模式（震宫·木，偏旺）**——情绪能量充沛，但也容易被情绪带着走
> 2. **原生家庭（坎宫·水，偏旺）**——与原生家庭的联结深，同时也承载了较多来自家族的情绪模式
>
> **能量偏弱的议题**：
> 1. **事业发展（离宫·火，偏弱）**——事业方向感和行动力有待激活，热情没有充分转化为事业上的推进力

### 第6章 核心议题深挖

**定位**：报告的核心章节，深入1-2个核心议题，给出"画面信号 → 失衡模式 → 本体状态 → 议题表现"的完整链条

**填充规则**：
- 每个核心议题独立成节
- 按"画面信号 → 五行失衡模式 → 本体状态链 → 议题化表现"的逻辑展开
- 语言要温暖、有洞察力，避免标签化
- 每个议题配一个"你可能会有共鸣的场景"，增加代入感

**信号层输入**：
- 支撑该议题的核心画面信号组合（视觉信号映射 第7章 信号组合→状态反向识别表）
- 对应的五行失衡模式（五行解读.md 第四章，含典型画面信号）
- 失衡模式到本体状态的映射链（原因端→结果端→长期衍生）

**数据来源**：
- 五行解读.md v0.3.0 20种失衡模式 + 信号→失衡快速索引
- 状态.md 状态体系
- 议题.md 议题化表达
- 视觉信号映射.md v0.1.1 信号组合反向识别表

> ⚠️ **数据源缺口（如实标注）**："议题化表现"环节所需的**状态×议题表现态矩阵当前不存在**（一个通用状态在特定议题下的典型表现句/共鸣场景）。共创期产出该矩阵（落 议题.md 各议题条目，MVP 前先填 8 外圈议题最小集）；**矩阵落地前，本环节的"共鸣场景"只能由模型自由生成、无知识库锚定**——这是报告链路最薄一环，直接关联报告采纳率（M-060），评审与验收时须显式知悉。

**示例模板**：

> #### 核心议题一：事业发展（离宫·火，偏弱）
>
> **画面信号**：离宫（正南方向）红色/橙色面积偏少、颜色偏浅，周围被蓝色（水）包围。
>
> **五行失衡模式**：**水多火灭（相乘）**
> - 原因端：水（情绪、思虑、恐惧）过旺
> - 结果端：火（热情、行动、方向）被克制
> - 长期影响：火越来越弱，形成"越不敢动→越没信心→越不敢动"的循环
>
> **本体状态链**：
> S-002 安全感不足 → S-011 情绪调节困难 → S-006 行动启动困难
>
> **在事业议题中的表现**：
> - 面对机会时容易先想到"万一失败怎么办"，思虑过多导致迟迟不行动
> - 职业上有拖延倾向，尤其是需要主动争取、展示自己的场合
> - 心里有想法、有热情，但一到要落地的时候就卡住了
> - 容易被他人的评价影响，担心做得不够好，干脆不开始
>
> **你可能会有共鸣的场景**：
> 心里有个想做的项目/想争取的机会，你在脑子里反复推演各种可能性，准备了很久，但真到要迈出第一步的时候，突然就没劲儿了，或者找各种理由推迟。事后又会自责"我怎么又没行动"。
>
> ---
>
> #### 核心议题二：情绪模式（震宫·木，偏旺）
>
> **画面信号**：震宫（正东方向）绿色面积大、颜色深，且有向外扩张的趋势。
>
> **五行失衡模式**：**木多土陷（相乘）**
> - 原因端：木（行动、情绪、成长欲）过旺
> - 结果端：土（承载、稳定、安全感）被消耗
> - 长期影响：地基不稳，越努力越累，容易 burnout
>
> **本体状态链**：
> S-021 执行功能受限 → S-012 成长受阻 → S-005 心理容器不足
>
> **在情绪议题中的表现**：
> - 情绪来得快、强度大，容易被小事触发
> - 想做的事情很多，同时开很多头，但很难坚持做完
> - 内在总有一种"不够快、不够好"的焦虑感，推着自己往前赶
> - 身体容易紧绷，肩颈、背部经常不舒服
>
> **你可能会有共鸣的场景**：
> 一天开始的时候雄心勃勃，列了一堆要做的事。做着做着就被各种情绪和新的想法带偏，到晚上发现没完成几件，又开始焦虑和自责。感觉自己像一根被拉得很紧的弹簧，松不下来。

### 第7章 生机与转化方向

**定位**：从问题视角转向资源视角，看到画面中的积极信号和转化可能性

**填充规则**：
- 找出画面中2-3个"生机点"（亮色、中心点、对称结构、流畅线条等）
- 每个生机点对应一个内在资源/转化方向
- 最后给出一个整体的转化路径

**信号层输入**：
- 正向信号识别（中心稳定结构、流畅过渡、暖色光点、向外舒展等）
- 三圈流动中的承接/贯通信号
- 各元素中的正向表达（不是所有信号都只看负向）

**示例模板**：

> 每一幅曼陀罗里，都同时藏着"问题"和"答案"。我们来看这幅画里的生机：
>
> **生机点一：中宫的黄色光点**
>
> 无论外圈多么复杂，中心始终有一个稳定的黄色区域。这意味着你的核心自我是稳定的，内在有一个"定海神针"。哪怕外在情绪波动大、行动卡壳，你内心深处其实知道自己是谁、要什么。
>
> 这个生机点对应的转化方向是：**回到中心，从内核出发，而不是从焦虑出发**。
>
> **生机点二：兑宫的粉色区域**
>
> 在关系的位置上，有一片柔和的粉色。这说明你在亲密关系中是有柔软度和感受力的，不是只会硬扛。这份柔软，其实也是你可以用来连接自己情绪的入口。
>
> 这个生机点对应的转化方向是：**通过关系中的柔软，学会对自己温柔**。
>
> **生机点三：外圈向外舒展的线条**
>
> 虽然行动层面有卡点，但外圈的线条是向外舒展的，不是收缩的。这说明你的内在其实有"向外走"的冲动和渴望，只是暂时被恐惧和思虑挡住了。
>
> 这个生机点对应的转化方向是：**从小步行动开始，把内在的舒展欲落实到具体的小动作上**。
>
> ---
>
> **整体转化路径**：
> 从中心出发（连接内核的稳定感）→ 通过柔软连接情绪（水的能量从"恐惧"转化为"滋养"）→ 用小步行动点燃热情（火的能量从"被压制"到"被激活"）

### 第8章 调理建议

**定位**：给出具体可操作的疗愈建议，按"清理-调理-显化"三方向组织

**填充规则**：
- 基于核心失衡模式和本体状态，从状态疗愈映射表中匹配方案
- 每个方向选2-3个具体建议，控制总量在6-8个，避免信息过载

**示例模板**：

> - 频率：每天1次，早上或睡前均可
> - 对应状态：S-011 情绪调节困难、S-002 安全感不足

> - 对应状态：S-011 情绪调节困难
> - 为什么对你有用：情绪卡在身体里，通过抖动可以直接释放，比想通更有效

> **1. 小步行动训练**

> - 对应状态：S-006 行动启动困难

> - 做法：穿红色/橙色的衣服，用红色的杯子喝水，在书桌放一个红色小物件
> - 频率：日常持续
> - 对应状态：火能量整体偏弱
> - 为什么对你有用：颜色是最直接的能量补剂，通过视觉直接补火

> - 做法：每天晚上写下当天的3件"小成就"或"小确幸"，哪怕再小都可以

> - 对应状态：S-016 身体承载不足、S-005 心理容器不足
