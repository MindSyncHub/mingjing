# GOLDEN-REPORT-SKELETON - 解读报告黄金骨架 v2（论点驱动）

> 版本：v2（2026-09-22，骨架 v1 修订——正向样本从豆包 Agent 版换为 Kimi 通用聊天版）
> 正向样本：`eval-results/external-probe/kimi-chat-d191-growth.md`（用户体验获疗愈师确认）
> 反面对照：`eval-results/external-probe/doubao-5067-wealth.txt`（Agent 模式，章节填表、标签式标题）
> 性质：风格基线。生产端报告 prompt 与 HTML 渲染从这里长。不是知识库内容，不进 RAG 注入。

---

## 一、格式决策（D-100）

- 输出格式 = **HTML 单文件**（内联样式），优于 PDF 与 Markdown。
- 视觉基调参照豆包样本的 HTML 呈现（奶油纸色 + 衬线标题 + 卡片化），但结构按本骨架 v2，不按它的章节。

## 二、体验原则（v2 核心，从正反样本对比提炼）

1. **定调置顶**：开篇一句话说出整幅画的主旨（「很想长、但还没扎下根」），读者 10 秒抓住全报告。
2. **论点驱动，不是章节驱动**：正文按「问题/论点」组织（当下的你→底盘→卡点→渴望→方向），不按三圈罗列、不设解释性章节（砍掉"写在前面""三圈地图"这类铺垫章）。
3. **标题即结论**：每个论点段的标题是一句判断（「成长的底盘：其实比你以为的稳」），不是栏目名（「三圈细读」「WEALTH」）。
4. **证据内嵌，三段式 bullet**：画面信号（加粗）→ 规则依据（属X/手册直断名）→ 含义翻译；随后一段「翻译成状态语言」的综合 prose，段尾一句金句收束（「底盘稳、苗还嫩」）。
5. **链条式综合**：跨信号推闭环（「受挫记忆→防御→行动变少→虚火→自我评判→更不敢动」），这是报告最有价值的部分，放在核心卡点后。
6. **总评呼应定调**：结尾回到开篇意象（「火候已到、木苗待壮」呼应「想长没扎根」）。
7. **篇幅克制**：正文 1500-2500 字量级；证据陈列不单列章节（生产端 claims 溯源走附录/悬浮标注，不打断阅读）。

## 三、章节骨架 v2

| 序 | 部分 | 职责 | 生产端数据源 |
|---|---|---|---|
| 00 | 定调 | 一句话主旨 + 半句画面依据 | 核心 accepted claims 摘要 |
| 01..N | 论点段（3-5 个） | 结论式标题 → 三段式证据 bullet → 综合 prose → 金句 | 五行/失衡/状态 claims + 气韵 |
| N+1 | 成长方向 | 按五行路径给 3-5 条，可操作建议（剂量照 状态疗愈映射 从本画推导） | 状态疗愈映射 |
| N+2 | 总评 | 呼应定调，赋能收束 | — |
| 附 | 待核对 + 免责声明 | 生产端特有：needs_human 清单 + 口径说明 | claims.json |

## 四、禁用清单（体系红线，报告 prompt 必须显性排除）

1. **五行能量图/打分条/能量条可视化**——通用大模型执念项，绝对拒绝；元素强弱用文字档位融入正文。
2. 不做心理/医学诊断，不做确定承诺；免责声明必带。
3. 不出现百分比；不数对称重复元素个数。
4. 三圈标记线不作证据、不赋予含义。
5. 不引入无出处的数字与"测量"表述。
6. 不用栏目名式标题（「05 · WEALTH」类）、不设与主题无关的解释性章节。

## 五、已定与待办

- **论点段组织原则（2026-09-22 疗愈师拍板）：混合式**——论点按题排序，每个论点内部的证据按内圈→中圈→外圈递进展开，既有主线又有圈的层次感。
- 待办：主题专章（财富/情感类报告的专章展开）在论点驱动结构下如何安置，待财富主题的正向样本回收后补。
