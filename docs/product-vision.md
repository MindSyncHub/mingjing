## 1. 愿景（Vision）

让每一位曼陀罗疗愈师都拥有一个 24 小时在线的 AI 搭档——既能生成专业的解读报告，又能陪伴来访者完成从理解到行动的探索旅程；同时让每一位来访者，在收到报告的那一刻起，就拥有一个懂自己的 AI 向导。

## 2. 使命（Mission）

用 AI 降低疗愈师的专业门槛和运营成本，让他们把更多精力放回"人"本身；用 AI 延伸疗愈服务的边界，让更多人能以更低的门槛接触和理解自己。

## 3. 目标用户

### 3.1 核心用户：曼陀罗疗愈师

- **用户画像**：个人执业 / 小型工作室
- 有专业基础，但缺乏标准化的话术体系和个案督导
- 时间精力有限，既要做服务又要做获客和运营
- 对 AI 有好奇，但不会写代码，需要开箱即用的工具
- 看重"流派纯正性"，不希望 AI 把不同流派的东西混在一起

### 3.2 延伸用户：来访者 / 报告接受者

- **用户画像**：接受过曼陀罗解读的普通用户
- 收到报告后想深入理解，但不好意思反复问疗愈师
- 对自我探索有兴趣，但不知道从哪里入手
- 需要一个安全、无评判的空间来消化报告内容
- 期待报告不只是"看一遍就放下"，而是能持续产生价值

## 4. 核心价值主张

### 4.1 对疗愈师

| 用户痛点 | 我们提供的价值 |
|---|---|
| 写解读报告耗时耗力，质量不稳定 | AI 报告生成：一键生成专业、结构化的曼陀罗解读报告 |
| 来访者反复问基础问题，消耗精力 | 报告问答助手：来访者自助探索，减少重复性答疑 |
| 缺少练习对象，成长全靠实战摸索 | 个案模拟练习：AI 扮演来访者，安全地练手 |
| 获客内容生产耗时耗力 | 内容流水线：一键生成朋友圈/小红书/社群素材 |
| 个案记录不规范，复盘难 | 结构化档案：自动整理个案记录，支持检索复盘 |
| 课程开发从零开始，效率低 | 课程辅助：自动生成引导词、学员手册、练习脚本 |

### 4.2 对来访者

| 用户痛点 | 我们提供的价值 |
|---|---|
| 报告看不懂，专业术语太多 | 通俗化解读：用大白话解释报告里的概念和结论 |
| 看完报告不知道下一步怎么办 | 引导式探索：从报告出发，引导用户深入理解自己 |
| 有些问题不好意思问疗愈师 | 匿名安全空间：随时提问，无评判，无压力 |
| 报告看一遍就放下了，没后续 | 持续价值：问答 + 练习建议，让报告从"知道"到"做到" |

## 5. 产品定位

**不是什么**：
- 不是替代疗愈师的"AI 疗愈师"——不做诊断、不开处方、不替代专业判断
- 不是通用的 AI 聊天工具——有明确的疗愈领域专业性和边界
- 不是单一功能的工具——是覆盖从报告到探索的完整工作台

**是什么**：
- 疗愈师的 **AI 副驾驶**：辅助决策，不替代判断
- 疗愈师的 **报告工厂**：高效生成高质量解读报告
- 来访者的 **报告解读助手**：帮助理解报告，引导自我探索
- 疗愈师的 **运营中台**：把重复工作自动化

## 6. 差异化

1. **流派插件化**：通用底座 + 流派插件，保证每个流派的"纯正性"，又能复用通用能力
2. **本体论驱动**：底层有跨流派概念映射，不同流派不是孤岛，可以对话和比较
3. **结构化 RAG**：不是普通向量检索，而是基于本体论的结构化知识组织，推理链条可追溯
4. **单端两场景设计**：解读参谋 + 应答准备，一套知识体系服务疗愈师的两个真实工作时刻
5. **报告 + 问答闭环**：不只是生成报告，而是从报告生成到问答探索的完整用户旅程

## 7. MVP 目标

**一句话验证**：
- 疗愈师用了 明镜 的报告生成 + 问答功能后，愿意持续使用，并觉得"确实帮到我了"
- 疗愈师能把 PDF 报告交付来访者并借助问答助手回应其提问（来访者不直接接触产品）

### MVP 只做两件事（双核心）

1. **曼陀罗绘画解读报告生成**：疗愈师上传曼陀罗画 + 用户信息，AI 生成结构化解读报告
2. **报告问答助手**（疗愈师端两场景）：
   - **解读参谋**：疗愈师自己把报告问透（生成后、交付前）
   - **应答准备**：来访者提问时辅助疗愈师组织回应（不直接面对来访者）

### MVP 不做的事

- 不做真实个案督导（缺少素材，需合作疗愈师）
- 不做获客内容生产（优先级靠后）
- 不做课程开发辅助（优先级靠后）
- 不做面向来访者的 AI 疗愈对话 / to C 自助形态（MVP 仅报告范围内问答）
- 不做多流派（MVP 只做曼陀罗一个流派，验证模式）
- 不做个案档案管理（MVP 后扩展）

## 8. 成功指标（MVP 阶段）

### 8.1 疗愈师侧

- **使用频率**：目标用户每周至少使用 3 次（M-065）
- **报告采纳率**：生成的报告，疗愈师觉得"可用"的比例 > 70%
- **问答满意度**：解读参谋场景问答满意度 ≥ 3.5 分（1-5 分制，M-064）
- **主观评价**：疗愈师愿意推荐给同行

### 8.2 交付与问答辅助

> **指标口径治理**：数值以 ACCEPTANCE §6.1 指标字典（M-NNN）为唯一口径源，本节数值为同步副本。

- **报告编辑率**：生成后改动字数占比 < 30%（越低越好）
- **问答辅助使用率**：报告生成后使用问答助手的比例 > 60%
- **交付完成率**：完成"生成 → 导出 PDF"的报告比例 > 80%
- 来访者侧反馈经疗愈师访谈间接收集

### 8.3 质量指标

- **报告准确率**：与疗愈师人工解读的一致性 > 80%
- **问答锚定率**：>90% 的回答有报告依据，不跑偏
- **安全越界**：0 条严重越界内容
- **边界清晰**：100% 敏感回答有口径提醒（应答准备场景按"可能被转述给来访者"标准审核）

## 9. 长期方向

MVP 验证通过后，按以下顺序扩展：

1. **增加更多流派插件**（人类图、塔罗、正念等）
2. **获客内容生产模块**
3. **个案档案与结构化管理**
4. **课程开发辅助**
5. **疗愈师社区与督导网络**
6. **来访者订阅服务**（持续陪伴式探索）
