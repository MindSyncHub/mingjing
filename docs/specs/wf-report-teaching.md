# wf-report-teaching.md - 教学版解读报告（任务契约）

> **版本**：v1.0.0（2026-10-19 本人拍板）　**更新日期**：2026-10-19
> 来源：task 013 三结构改造的第一执行项。验收标准未确认前不动工实现。
> 形态（2026-10-19 本人定）：**主题手册为主体 + 真案例篇**，范例为 `eval-results/blind-2026-10-cases/case-001/rounds/E-豆包工作.md`（值得感主题手册）。

## 1. 解决什么任务

目标用户是 **AI 素养不高的新人疗愈师**（task 013 设计约束）。来访者版报告告诉她「结论是什么」，教学版告诉她「**这个结论是怎么从画上推出来的，下次你自己怎么看**」——报告是逻辑推理的教材，长期目标是疗愈师摆脱 AI 独立临在（D-011⑧）。

与问答智能体的边界（task 013 纪律）：教学版是**静态预判**（生成时一次性给出），问答是交互式追问，功能不重叠。

## 2. 输入 / 输出

**输入**：

| 输入项 | 说明 |
|---|---|
| 三圈标记定稿图 + 原图 | 与来访者版同一输入 |
| 来访者主题 | 与来访者版同一主题（第一轮统一「财富」） |
| KB 主题知识包（主知识源） | 按主题从 knowledge/healing/ **确定性装配**（库规模 64 篇，不需要向量 RAG）；装配清单在 `schools/mandala/theme-packs/`（2026-10-19 本人定：教学版引用体系知识库而非手册原文）。KB 未覆盖处在文中标注「（体系待补）」，作为缺口回补知识库；手册原文不进教学版上下文 |
| report.md（来访者版初稿） | **一致性硬约束的来源**：教学版讲解的推理必须与来访者版结论一致，不另起炉灶（task 013：两版底层推理必须一致，每条结论可回溯到画面证据） |

**输出**（随同一 run 目录落盘）：

| 产物 | 说明 |
|---|---|
| teaching.md | 教学版正文（Markdown） |
| teaching.html | 渲染版（复用 render_report_html 链路） |
| prompts/30-teach.md | 教学版调用的 prompt 原文落盘（可审计） |

## 3. 结构（沿用示例手册章节，案例篇换真案例）

1. **主题认知篇**：主题是什么、常见来源、在生命中的表现、为什么曼陀罗适合做这个主题、解读师定位与边界
2. **主题解读篇**：本主题的三圈定位、三圈信号解读、颜色信号速查、五行失衡关联、修复回路、形状信号、综合判断对照表
3. **主题个案实操篇**：个案准备、引领觉察问题清单、主题解读标准句式与示范、清理方案、订单画方案、检视与信念锚定、金句库
4. **疗愈方案篇**：主题周期计划（示例为 21 天三段式）、清理画用色速查、观想脚本、陪跑跟进要点
5. **真案例篇（每图一份，替代示例的虚构案例示范）**：用**本幅画**走完整个案逻辑链——图面特征（三圈归属以标记图为准）→ 逐条推理（画面信号 → 手册依据 → 结论）→ 与来访者版结论的对照讲解 → 根源挖掘引导 → 清理/滋养/显化方案
6. **附则**：伦理边界与转介指引、解读师自查清单、主题延伸

**复用策略**：第 1~4 章与第 6 章是**主题级资产**——同一主题（如「财富」）生成一次可复用；第 5 章**按图生成**。黄金集 10 图统一财富主题时，手册主体只生成一份。

（2026-10-19 本人补充：完全复用是本版本的简化选择——每幅画不同，教学侧重本应随画调整；待知识库完善后再评估手册部分按画差异化。）

## 4. 完成判据（验收标准，逐条可判）

1. **一致性**：第 5 章的每个结论都能在 report.md 中找到对应结论，不矛盾；画面事实描述与画面一致（以审计臂核查为准）
2. **知识忠实**：所有规则性说法以 KB 主题知识包为准，引用时注明来源（文档名或稳定 ID），不说「手册说」；知识包未覆盖但教学需要的内容可补写，但该句必须带「（体系待补）」标注——这些标注即知识库回补的缺口清单
3. **负向给生机**：所有负向解读都给出修复路径（手册原则，示例 5.4 复盘要点）
4. **红线**：过审计臂合规核查（诊断/承诺/负向打压/危机未转介，与来访者版同一套）
5. **新人可读**：无工程术语、无 AI 腔（D-012 语态同样适用）；称呼读者用「你」或不称呼，不用「徒弟」这类师徒称谓（2026-10-19 本人定）；章节结构照上述六项，标题是内容句不是栏目名
6. **案例篇真实**：第 5 章只用本幅画，不虚构案主背景（画者信息未知时不编造，只讲画面与推理）

呈现约束（2026-10-19 本人定）：HTML 渲染时知识来源标注（「（…来源：…）」括号引注）弱化显示——字号缩小、颜色变浅，不打断正文阅读；渲染层规则映射实现，不依赖模型改写法。

## 5. 绝对不做

- 不替代疗愈师做解读裁决（教学版是教材，不是标准答案；手册原则：以你的神为准）
- 不虚构案例与案主（示例手册的虚构案例示范在本产品中全部换真案例）
- 不做主题手册的自动入库——主题级资产是否沉淀为可复用手册，由本人逐份拍板
- 不在教学版中讨论报告范围外的深度疗愈话题（同 1.5 红线）
