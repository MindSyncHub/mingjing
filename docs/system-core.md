## 一、体系设计原则

### 1.1 东方本体为根，现象方法为用

- **本体为根**：解读框架以东方能量体系（阴阳、五行、三才、八卦）为本体层，提供整体观和全局视角。八卦九宫作为先验框架，是体系的空间结构基础（画面读取适用边界见 术/流派/曼陀罗/解读用法.md：中心对称画面信息折叠，议题由来访者输入确定）。
- **现象为用**：用户沟通、日常干预、效果评估采用心理学方法（无论东方还是西方来源）作为现象层，提供结构化、可操作、可验证的工具。

> 划分依据是**研究层次（本体/现象），不是地域**——与 道/体系原则.md §1.2 口径一致。

为什么要双轨：

- 东方体系长于整体观和能量调节，但语言晦涩、难以量化、不便于普通用户理解
- 西方心理学长于结构化和可操作性，但容易碎片化、缺乏全局观
- 两者结合，各取所长

### 1.2 八卦为位，状态为用

- **八卦为位**：议题按八卦宫位（人生领域）划分，8个外圈议题 + 4个中圈方向 + 1个内圈核心，共13个层次化的议题节点
 - **中圈 4 方向（定义，四象五行向）**：木向·成长行动（生发、规划、执行）／火向·表达热情（展现、热情、方向）／金向·关系价值（边界、价值、收成交换）／水向·情绪根基（感受、安全、根基）；土居中宫（内圈核心），不占中圈方向
- **状态为用**：存在状态是跨议题的通用层，同一个根状态可以在多个宫位（议题）中显化为不同的表现态
- 议题归属判断：先定位（哪个领域的问题），再找根（底层是什么状态）

### 1.3 三才为层，由表及里

- 三才（天/人/地）对应问题的深浅层次
- 探索路径：地位（具体问题）→ 人位（核心模式）→ 天位（根源信念）
- 干预路径：可以从任意一层切入，但深层改变需要触达天位

## 二、东西方双轨体系的关系

### 2.1 两者是相关关系，不是等同关系

东方说的是**能量维度**（能量的性质、位置、盛衰），西方心理学说的是**心理/行为维度**（认知、情绪、行为模式）。

- 不是"同一个东西的两种表述"
- 而是"两个不同描述维度的交叉验证"

### 2.2 三层对应关系

**第一层：现象对应（初步实证）**
现有案例样本（11 例完整解读案例，索引见 knowledge/healing/cases/索引.md）**初步观察提示**，特定能量失衡模式与特定心理行为模式存在相关性（**样本有限，待逐状态系统复验**，分级口径见 状态疗愈映射 §1.3）：

- 离火不足 ↔ 职业认同危机、自我效能感低
- 坎水不足 ↔ 不安全依恋、安全感缺失
- 震木郁结 ↔ 情绪抑制、持续低落
- ……

这是从现有案例样本中归纳出来的现象规律，不是理论推导；样本量仍小，相关性结论待更多案例与疗愈师共创验证后升级置信度。

**第二层：机制假设（工作模型）**
工作假设：能量状态是底层，心理行为是表层。能量失衡会显化为心理行为模式，心理行为模式也会反过来影响能量状态。

这个假设用于指导实践，但不宣称是终极真理。

**第三层：干预互补（实操层面）**

- 东方方法（曼陀罗、经络等）→ 直接调能量层面，见效快，但容易反弹（心理模式未改）
- 西方方法（心理咨询、CBT等）→ 调心理和行为层面，效果持久，但见效慢
- 配合使用：先用东方方法快速调整能量状态，让用户先感受到变化；再用西方方法处理心理模式，让效果持久

## 三、关键概念辨析

### 3.1 宫位五行 vs 能量五行

- **宫位五行**：每个宫位（方位）自带的五行属性（如乾宫属金）——这是领域属性，决定这个宫位的"本性"
- **能量五行**：调节时使用的能量属性（如调财富常用土）——这是解决方案属性，取决于当前是过旺还是不足

两者不是一回事。同一个宫位的问题，根据能量状态的不同（过旺/不足），调节用的五行也不同。

### 3.2 议题表现态 vs 通用状态

- **通用状态**：跨领域的根状态和核心状态，如"配得感不足""安全感缺失"
- **议题表现态**：通用状态在特定议题（领域）下的具体表现形式，如"不敢谈钱"（财富）、"不敢接受爱"（关系）

关系：一个通用状态 → N个议题表现态（每个议题一个）

### 3.3 主动聚焦 vs 深层浮现

- **主动聚焦**：用户主动提出的主议题，通常在外圈（地位）
- **深层浮现**：探索过程中自然触达的更深层议题，从中圈（人位）到内圈（天位）

浮现不是随机的，而是沿着"同方位深入 + 五行生克联动"的路径有规律地发生。

### 3.4 用户入口名 vs 能量名

- **能量名**（深层/专业用）：体现宫位的核心能量本质，如"热情与方向""安全感与根基"
- **议题名/用户入口名**（表层/用户用）：用户能听懂、会主动描述的问题领域，如"事业发展""原生家庭"

两个名字用在不同场景：专业讨论和体系内部用能量名，用户沟通和产品入口用议题名。

## 四、设计过程中的关键决策记录

### 4.1 为什么从18个平铺议题改成三才八卦结构？

- 原问题：18个议题平铺，缺少结构，议题之间的关系不清晰；"主动选择/被动浮现"机制缺乏底层支撑
- 决策依据：曼陀罗解读体系本身就是三才+九宫的空间结构，议题层从这个框架里长出来，天然自洽
- 收益：
  - 议题之间有了明确的空间关系和层次
  - 浮现机制有了清晰的路径（从外到内、同方位深入、五行生克联动）
  - 与曼陀罗解读体系完全打通，解读和议题是一套逻辑

### 4.2 为什么去掉"用户入口"这个概念？

- 原问题："用户入口"和"议题"是两个概念，但边界模糊，容易混淆
- 决策依据：议题层是知识体系层面的设计，不绑定具体产品形态（菜单式还是对话式）。不管产品形态是什么，最终都会聚焦到一个议题上
- 收益：议题层的定位更纯粹——就是知识分类和导航体系，不掺和产品交互的事

### 4.3 为什么要区分"宫位五行"和"能量五行"？

- 原问题：容易混淆"问题在哪个宫位"和"用什么能量调"，导致逻辑矛盾（比如财富属金但用黄色土调）
- 决策依据：宫位是位置/领域属性，能量调节是解决方案属性，两者维度不同，可以不一致
- 收益：逻辑更严谨，解释了为什么"同一个宫位的问题可以用不同五行来调"（取决于过旺还是不足）

### 4.4 为什么东西方是"相关关系"不是"等同关系"？

- 原问题：如果直接说"离火不足就是职业认同危机"，两边都不成立——东方体系不这么说，西方心理学也不认
- 决策依据：两个体系的基本假设不同（能量 vs 心理），不能直接划等号。但在现象层面观察到明显相关性（样本有限），可以互相印证、互补使用
- 收益：既保持了学术严谨性，又不影响实际应用

## 五、待验证的假设

以下内容目前为理论推导或部分验证状态，待更多个案数据确认：

1. **每个议题"过旺/不足"的具体表现形式**——需要更多个案归纳验证，目前是理论推导+部分个案观察
2. **每个议题的调节方向和具体方法**——需要大量实践验证效果，特别是调节的具体操作（颜色选择、画法、位置、时长等）
3. **九宫联动的具体路径和规律**——需要系统观察跨宫问题的浮现模式，目前只有五行生克的理论框架
4. **东方能量状态与西方心理状态的相关性量化**——需要标准化测评工具验证，目前是定性观察
5. **三才三层的精确对应关系**——地位到人格、人位到核心、天位到本源，这个分层是否足够？需不需要更细的分层？
6. **8个外圈议题的完备性**——人生问题是不是刚好8类？有没有遗漏的重要领域？目前是按八卦框架来的，还需要用户研究验证

## 六、后续可以深入的方向

1. **方案层建设**：给每个议题、每种能量状态（过旺/不足）、每种工作方向（清理/调理/显化），配上具体的干预方案（曼陀罗画法、心理学练习、身体工作等）
2. **典型浮现路径图谱**：整理常见的跨宫、跨层浮现路径，做成"问题地图"，帮助疗愈师快速定位和导航
3. **评估工具开发**：开发东方能量状态的自评工具（类似心理量表），让能量状态可量化、可追踪
4. **个案数据库建设**：系统收集个案数据，验证和修正当前的理论假设，特别是过旺/不足的表现和调节效果
5. **12宫扩展**：在九宫基础上，扩展到12宫（十二地支），支持更精细的身体对应和细分议题
