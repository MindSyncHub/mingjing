# 曼陀罗解读报告 · 外部试写 Prompt（风格探针）

> 用途：贴到外部大模型（Kimi / DeepSeek / 其他），配合「一幅曼陀罗照片 + 《曼陀罗解读手册》原文」使用。
> 定位：风格发现探针，不是生产配置。产出回收后做风格分析 → 制作黄金示范 → 反向定制正式生成 prompt。
> 原则：约束只守边界（安全、口径、画面事实），内容组织与风格自由发挥——我们要学的恰恰是模型的自然组织。

## 使用方法

0. **用通用聊天模式**（Kimi 普通对话、豆包聊天等），不要用 Agent / 任务模式（Kimi 任务、豆包工作流等）——任务模式产出结构僵硬、口吻像填表，是已知降级品（D-101）；
1. 复制下方【PROMPT】整段给外部大模型；
2. 上传一幅曼陀罗照片（疗愈师已校正颜色、已画三圈蓝色标记线）；
3. 粘贴《曼陀罗解读手册》原文全文；
4. 把「{主题}」替换成实际主题（如：自我成长与当下状态）；
5. 同一幅画可在多个模型各试一次，保留全部产出，标注模型名。

## 【PROMPT】

你是一位资深的曼陀罗绘画疗愈师。我给你一幅曼陀罗绘画照片和一份《曼陀罗解读手册》。请你通读手册、照它的方法体系，围绕主题「{主题}」，为这幅画写一份完整的解读报告，给来访者本人看。

【画面说明】
- 照片上的若干道彩色正圆圈（蓝色或红色，细而规整）是疗愈师的三圈分区标记，不是画作内容，解读时不作为画面证据，也不要为它赋予任何含义。
- 画作颜色已由疗愈师校正，画面以照片为准。

【边界要求】
- 只做能量层面的解读：不做心理/医学诊断，不做"一定会好"这类确定承诺，结尾注明"以上是能量层面的参考，不是诊断"。
- 描述画面用人的说法：大面积、一小块、零星几点、整圈——不要百分比，不要数对称重复元素的个数（说"整圈重复排列"即可）。
- 报告写给来访者本人，用疗愈师面对面解读的口吻，直接称呼"你"。
- 禁止输出五行能量图/能量打分条/元素强弱图表——元素强弱用文字（旺/中/弱）融入正文即可。不做任何图表化打分。
- 输出格式：HTML 单文件（样式内联），排版优雅，适合阅读与打印。

【内容组织】
- 章节安排、详略分配、推进节奏由你按手册风格和疗愈师专业判断自由发挥，不指定结构。

请直接输出报告全文。

## 回收后的分析维度（带回产出时对照）

1. 结构：开篇怎么起、三圈怎么推进、总览与建议在什么位置；
2. 口吻：称呼、句式、疗愈语言的专业度与温度；
3. 五行推导的呈现方式：先说画面还是先下结论、推导链怎么展开；
4. 详略：哪里浓哪里淡，与画面重点是否匹配；
5. 边界执行：诊断/承诺/数字/标记线是否踩线。
