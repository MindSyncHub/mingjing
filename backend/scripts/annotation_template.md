# 黄金集人工评测模板（疗愈师填写）——识别准确率 + 约束层松紧度

> 用途：评测「识别」是否准确 + D-097 确定性校验的误杀/漏杀，不是评测「解读结论」是否一致。
> 结论（失衡模式 / 状态 / 议题）不同疗愈师本来就可能选不同组合，不作为硬指标；只有「识别」准确、结论逻辑通顺，才 OK。

## 一、评测对象（D-095/097 新链三件套）

对照「机器识别结果」逐条打分。程序像素视图已退出证据链（D-095），不再作为评分对象或参照。

1. **感知描述（评审主对象）**：run 目录下 `perception.md`——Kimi 产出的自然语言画面描述全文。先通读，对照原图把握整体颗粒度与遗漏。
2. **色块清单（逐块核对用）**：run 目录下 `signals.json` 的 `blocks` 数组——每块含颜色（color_raw 原文色名）、数量档位（主导/较多/少量/点缀）、形状简述、位置、相邻关系、quote（感知原文引文）。
3. **推理产物（约束层评审用）**：run 目录下 `claims.json`——`accepted` 与 `needs_human` 分栏，每条带降级原因（needs_human_reason）与出处警告（provenance_warnings）。

run 目录位置：跑批记录（`eval-results/run-<时间戳>.json`）里每条记录的 `run_dir` 字段。

## 二、四个识别维度（每幅画）

| 维度 | 评什么 | 关键边界 |
|---|---|---|
| 颜色识别 | 每个色块的颜色名对不对 | 粉≠红、米白≠黄、深紫/浅紫、明橙/淡橙、灰≠蓝、黄绿归绿（KB §4.1.2） |
| 位置识别 | 每个色块在内/中/外圈的归属对不对 | 只到圈层，不读宫位 |
| 色块识别 | 同色连续区域有没有正确切成一块、不同色有没有正确分开 | 被描边/留白（白属金）隔开的是两块；同色同形重复纹样按一个视觉群；成对小组（左右两撇）算一块 |
| 相邻关系 | 谁和谁相邻对不对 | 像素直接相连、或仅隔描线（线两侧算相邻）；留白/白色块隔开不算 |

## 七、评分权重与口径提醒

- **漏报「主导/较多」色块 = 识别错误**；漏报「少量/点缀」= 可接受、权重低。
- **边环检查位**：每圈外缘/内缘的独立颜色边环（哪怕细长）应单独报出；外圈最外缘一圈是固定重点检查位。边环重要性按画面个案判断。
- 失衡门槛口径（五行解读 §4.2/§4.3.4，D-097 固化为机械校验）：①按实际相邻对峙部分比较，不用全圈总量；②点缀级不参与对峙只作佐证；③双方至少「少量」档且不同档才成立结构性失衡；④同档相邻只论局部生克不和（水火不容）；⑤金多木折（IM-14）为高频直断，豁免③④。
- needs_human 不是「错误」，是「机器没把握、请你核对」。评审重点是统计四件套的误杀率，为验收层阈值裁决提供数据。
- 只评「识别对不对」和「约束拦得对不对」，不评「解读好不好」。
- 拿不准就标「不确定」，不要硬凑。
- 同一幅画两人独立评，先不互相看，评完再仲裁分歧。
