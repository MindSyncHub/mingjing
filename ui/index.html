这是什么

明镜是一个 localhost 单用户的疗愈师工作台：上传一幅曼陀罗绘画，视觉模型生成解读报告， 第二条 AI 链路对报告做合规红线与「超纲」核查，疗愈师终审后交付。 定位是辅助工具——不做诊断、不做承诺，最终判断永远在疗愈师。

架构：通用底座 + 流派插件 + 工作流

  • 输入预处理：OpenCV 确定性流水线（矫正 → 裁切 → 基准圆检测 → 圈界提议），不经 AI——确定性问题交给代码
  • 报告生成：gen-audit 三步链（生成 → 合规与超纲核查 → 确定性渲染），每步 prompt 与产物全量落盘可追溯
  • 报告问答：基于报告内容的疗愈师问答助手（解读参谋 / 应答准备两场景），回答带规则引文

三层评定的「锚定事实层」上线三天后被证明不可维护，新增 D-016 正式撤销 D-015——决策日志保留完整时间线，不掩饰。

D-111 · 零框架零构建

本界面无 React、无 npm、无 CDN——一个 uvicorn 进程托管全部静态文件与 API。刻意约束，知道什么时候不引入复杂度。

边界与隐私

所有 AI 输出遵守：不做诊断 / 不做承诺 / 不越界 / 危机信号立即转介。 评测画作图像不进入版本库；来访者个案数据不离开本机。 AI 是辅助工具，最终判断在疗愈师。
